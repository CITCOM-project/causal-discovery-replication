# CARLA data

The data in this directory is taken from [this repository](https://github.com/CITCOM-project/carla-case-study/tree/main/studied-cases/data) and is associated with [this paper](http://doi.org/10.1145/3756681.3756967).
Specifically, it is a concatenation of the following files:
  - TCP_privileged_data.csv
  - TCP_trained_data.csv
  - garage_privileged_data.csv
  - garage_trained_data.csv
