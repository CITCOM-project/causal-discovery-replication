# Causal Test Adequacy Data
The data in this directory is taken from [this repository](https://orda.shef.ac.uk/articles/software/Causal_Test_Adequacy/24422104?file=43722984) and is associated with [this paper](https://doi.org/10.1109/ICST60714.2024.00023).

We consider the three separate case studies from this repository, and have concatenated all of the data in the `baseline` subdirectory for each case study.
