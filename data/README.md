# Data from real systems

This directory contains data from several real software systems that have previously been used for causal testing.

- [giamattei_2024_carla.csv](https://doi.org/10.6084/m9.figshare.21937121)
  The data in this file comes from the replication package of [this paper](https://doi.org/10.1145/3635709), specifically 'Replication-package/data-analysis/all_data/raw_data/data_combined_all.csv'.

- [foster_2024_carla.csv](https://github.com/CITCOM-project/carla-case-study)
  The data in this file is taken from [this repository](https://github.com/CITCOM-project/carla-case-study/tree/main/studied-cases/data) and is associated with [this paper](http://doi.org/10.1145/3756681.3756967).
  Specifically, it is a concatenation of the following files:
    - TCP_privileged_data.csv
    - TCP_trained_data.csv
    - garage_privileged_data.csv
    - garage_trained_data.csv

- The following files come from [this repo](https://github.com/CITCOM-project/CausalTestingFramework/tree/24103e04d171a79f0907b0bc6540c798e61e6fbb/examples) and support [this paper](https://doi.org/10.1145/3607184).
  - [clark_2023_poisson.csv](https://github.com/CITCOM-project/CausalTestingFramework/blob/main/examples/poisson-line-process/data/random/data_random_1000.csv)
  - [clark_2023_lr91.csv](https://github.com/CITCOM-project/CausalTestingFramework/blob/24103e04d171a79f0907b0bc6540c798e61e6fbb/examples/lr91/data/normalised_results.csv)
  - [clark_2023_covasim_beta.csv](https://github.com/CITCOM-project/CausalTestingFramework/blob/24103e04d171a79f0907b0bc6540c798e61e6fbb/examples/covasim_/doubling_beta/data/10k_observational_data.csv)
  - [clark_2023_covasim_vaccines.csv](https://github.com/CITCOM-project/CausalTestingFramework/blob/24103e04d171a79f0907b0bc6540c798e61e6fbb/examples/covasim_/vaccinating_elderly/simulated_data.csv)

- [foster_2024](https://orda.shef.ac.uk/articles/software/Causal_Test_Adequacy/24422104?file=43722984) comes from the replication package of [this paper](https://doi.org/10.1109/ICST60714.2024.00023), specifically from concatenating the data files in `case-study-3/data/baseline`.
